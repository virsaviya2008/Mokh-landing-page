# Мох — текст для Behance

## Название проекта
Мох — лендинг программы восстановления после выгорания

## Описание (поле Description)
Концепт сайта для онлайн-программы восстановления после выгорания.

Идея — страница, которая «оживает» по мере прокрутки: в начале всё чёрное, серое и пустое, к концу появляются мох, свет и цвет. Шкала заряда справа показывает, как далеко вы продвинулись: от «Пусто» до «Цветение».

Что сделано:
— интерактивный первый экран: камень реагирует на курсор
— шкала заряда по ходу страницы, у каждой секции свой этап
— анимированные счётчики, раскрывающиеся стадии выгорания, расписание групп
— тарифы с переключателем месяц / год
— адаптивная вёрстка под телефон

Стек: HTML, CSS, JavaScript без фреймворков.
